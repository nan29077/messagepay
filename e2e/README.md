# E2E 브라우저 검증 (삭제 금지)

실제 크로미움을 띄워 **화면을 클릭·입력해** 문자페이가 깨졌는지 확인하는 스크립트입니다.
`tests/*.test.ts`(Vitest)는 서버 로직만 봅니다. 여기가 없으면 **화면이 깨졌는지 확인할 방법이 사라집니다.**

> 2026-08-21 커밋 `99da66b` 에서 "사용하지 않는 스크립트"로 오해받아 9개가 통째로 삭제된 적이 있습니다.
> 그래서 `e2e/` 로 옮기고 `npm run test:e2e` 로 묶었습니다. **지우지 마세요.**

## 실행 방법

```bash
# 1) 터미널 A — 앱 실행
npm run dev

# 2) 터미널 B — 전체 검증 (스크립트마다 DB 초기화·재시드)
npm run test:e2e

# 일부만
npm run test:e2e -- round10 studio

# 재시드 없이 (빠르지만 실행 순서에 따라 결과가 달라질 수 있음)
npm run test:e2e -- --no-reseed
```

처음이라면 브라우저를 한 번 받아야 합니다.

```bash
npx playwright install chromium
```

사전 설치된 크로미움을 쓰는 환경(컨테이너 등)은 경로를 넘기면 됩니다.

```bash
E2E_CHROMIUM=/opt/pw-browsers/chromium npm run test:e2e
```

다른 주소로 띄웠다면 `E2E_BASE=http://localhost:3000` 처럼 지정합니다.

## 구성

| 스크립트 | 무엇을 지키는가 |
|---|---|
| `round5-e2e.mjs` | 스튜디오 셸·사이드바 정보구조, 메뉴 10종 실제 진입, 모바일 햄버거 |
| `round6-e2e.mjs` | 후원샵 PC/모바일 분기 + **PC 웹 후원 PIN 인증 전 구간**(금액·메시지 → 번호 → PIN 링크 문자 → PIN 입력 → 완료 → 최근 후원 노출) |
| `round7-e2e.mjs` | 고객센터 문의 접수·게스트 스레드 승계, 최고관리자 문의 검색/필터/답변, 로그인 CSRF, `/api/health` 축소 |
| `round8-e2e.mjs` | 정산 탭 4종, **원천징수 미리보기(소득세 3% + 지방소득세 10% + 소액부징수)**, 주민등록번호 수집, 정산 계좌, 금칙어 추가/중지/삭제 |
| `round9-e2e.mjs` | 지급대행·원천징수 CSV 권한(401/403/400), 배치번호 가드, 관리자 권한 5종, 개인정보 표시 원칙 |
| `round10-e2e.mjs` | 알림 버튼(PC 우측 상단·모바일 햄버거 왼쪽), **정산 요청 → 최고관리자 알림함 도착**, 영업일 5일 정산주기 안내·캘린더 범례, 공휴일 등록/삭제, 오버레이 SSE·테스트 후원 표시 |
| `gap-e2e.mjs` | 기기별 안내 문구가 서로 새지 않는지, 모의(mock) 고지, 공개 페이지 스모크 |
| `studio-e2e.mjs` | 유튜브 mock OAuth 연결·해제·재연결·거부, 오버레이 URL 발급·설정 저장, 스트림 키, 후원 설정·프로필 저장 |
| `admin-e2e.mjs` | 관리자 28개 화면 전수 스모크, 한도 정책 15개 필드와 정책 등록 |

`_helpers.mjs` 는 공통 로그인·리포터·모의 발송함 조회를 담습니다.

## 결과 읽는 법

각 줄이 `PASS | 검사 이름` 또는 `FAIL | 검사 이름 | 사유` 로 나오고, 끝에 요약이 붙습니다.
하나라도 실패하면 종료코드가 1 이라 CI 에서도 그대로 쓸 수 있습니다.

## 주의

- **시드 데이터에 의존합니다.** 계정·코드·MO 번호는 `_helpers.mjs` 의 `SEED` 에 모아 두었습니다.
  시드를 바꾸면 그 상수만 고치면 됩니다.
- `mock` 어댑터 기준입니다. 실제 헥토/엠투넷 연동 후에는 결제·문자 구간을 연동 규격에 맞게 다시 손봐야 합니다.
- 개발 서버(dev)는 첫 진입마다 컴파일이 끼어들어 느립니다. 전체 실행에 10~20분 걸릴 수 있습니다.
